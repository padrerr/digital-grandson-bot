# Цифровой внук — Telegram-бот

## Локальный запуск

1. Установите Python 3.11+.
2. Создайте виртуальное окружение:
   python -m venv .venv
   source .venv/bin/activate   # Windows: .venv\Scripts\activate
3. Установите зависимости:
   pip install -r requirements.txt
4. Скопируйте .env.example в .env и заполните:
   - BOT_TOKEN — получите у @BotFather
   - ADMIN_CHAT_ID — ваш Telegram ID (узнать у @userinfobot)
   - GIGACHAT_CREDENTIALS — опционально
5. Запустите:
   python bot.py

## Деплой на VPS (российский)

1. Возьмите VPS в Yandex Cloud / Selectel / Timeweb — от 200 ₽/мес.
2. Установите Docker и docker-compose.
3. Создайте systemd-юнит или используйте docker-compose.
4. Положите .env рядом с проектом.

## Что уже работает

- Регистрация родственника и пожилого (по ссылке-приглашению).
- Согласие на ПДн (152-ФЗ) кнопкой.
- Добавление и удаление задач распорядка с временем.
- Автоматическая отправка напоминаний в заданное время.
- Кнопки «Сделано / Пропустила / Позже».
- Повтор через 20 минут, тревога через 60 минут (настраивается).
- Ежедневный вопрос о самочувствии.
- Кнопки самочувствия, мгновенная тревога при «плохо»/«помощь».
- Свободный текст: правила + GigaChat.
- Вечерний отчёт и отчёт за 7 дней.
- Кнопка «Нужна помощь с уходом» — задел под «Добросмену».
